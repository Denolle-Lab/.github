# Denolle Lab

Seismology, geohazards and computational geoscience at the University of Washington, Earth and Space Sciences. Website: [denolle-lab.github.io](https://denolle-lab.github.io/)

**How we work.** We run the entire research practice through computational tools and openness. Data access, processing, modeling, agentic pipelines, figures and review all live in versioned code. Openness is our starting contract: a project begins as a public, documented repository that anyone can rerun and check.

## Our software

**[awesome-denolle-lab](https://github.com/Denolle-Lab/awesome-denolle-lab)** is the curated list of lab packages, workflows and reproducibility repositories, grouped by theme. A few active ones:

| Repository | |
|---|---|
| [seisfetch](https://github.com/Denolle-Lab/seisfetch) | Fast miniSEED download from EarthScope, SCEDC, NCEDC and other FDSN servers |
| [codameter](https://github.com/Denolle-Lab/codameter) | Operational seismology as reproducible, shareable practice ([site](https://denolle-lab.github.io/codameter/)) |
| [surfcat](https://github.com/Denolle-Lab/surfcat) | 25-year catalog of seismic surface events in the Pacific Northwest |
| [cascadia_obs_ensemble](https://github.com/Denolle-Lab/cascadia_obs_ensemble) | Offshore Cascadia earthquake catalog from ensemble deep learning |
| [meta-seismology](https://github.com/Denolle-Lab/meta-seismology) | Interactive map of 5,272 observational seismology studies, 2021 to 2025 |
| [gesc-python](https://github.com/Denolle-Lab/gesc-python) | Surface-wave modes, Scholte coupling and phase-change depth inference |
